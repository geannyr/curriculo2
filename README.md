## Execução local

O projeto é um site estático e não exige instalação de dependências ou processo de build.

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` diretamente no navegador.

Como alternativa, sirva a pasta com uma extensão como Live Server no VS Code. É necessário acesso à internet para carregar as fontes e os ícones externos.
